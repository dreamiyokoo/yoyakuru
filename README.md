# ヨヤクル（yoyakuru）

電話もチャットも、AIが予約受付。

株式会社ドリーミが検討する、マルチテナント型のAI予約SaaSです。店舗ごとの予約・営業時間・メニューを管理し、Googleカレンダーと連携する構想です。月額課金にはStripeを想定しています。

## 現在の状態

企画・技術検証前の段階です。実装や稼働実績を示すものではありません。

- サービス名：ヨヤクル（決定）
- 音声応対：OpenAIの音声会話APIを第一候補とする
- 第一号クライアント候補：伏見整体院（契約・導入決定は未確認）
- 販売価格・電話事業者・採用モデル：未決定
