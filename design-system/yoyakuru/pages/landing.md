# ランディングページ（LP）の上書きルール

作成日：2026-11-05。MASTER.md（UI UX Pro Maxの提案）に対し、ヨヤクルのLPでは次を優先する。

## 構成

提案の「Hero + Testimonials + CTA」から、お客様の声を外す。導入実績がまだないため、架空の声・利用店舗数は載せない。

1. ファーストビュー（キャッチ、補足、申し込みボタン、体験ボタン）
2. 課題（施術中に電話に出られない、予約が散らばる）
3. 解決（AI電話、Web・チャット予約、1つの予約台帳）
4. 始め方の3ステップ（AIと会話して設定 → 公開と電話の転送 → AIが受付）
5. 機能
6. 体験（架空の整体院に電話・チャットで予約してみる）
7. 料金（価格はIssue #1の後。今は「先行導入の店舗を募集中」）
8. よくある質問
9. 先行導入の申し込み

他社との比較は、社名を出さず「一般的な予約システム」「一般的なAI電話」との違いとして書く。

## フォント（日本語）

提案のLexend / Source Sans 3は英字用のため、日本語では次を使う。

- 見出し：Zen Kaku Gothic New（Bold）
- 本文：Noto Sans JP（Regular／Bold）。本文は16px以上、行間1.5以上

## 色

MASTER.mdの配色を使う。ただし、白文字のボタンは提案のPrimary（#0891B2）ではコントラスト比4.5:1を満たさないため、一段濃い #0E7490 を使う。

| 用途 | 色 |
|---|---|
| ボタン（白文字） | #0E7490 |
| 強調・リンク | #0891B2 |
| アクセント（チェック・アイコン） | #059669 |
| 背景（セクションの交互） | #ECFEFF ／ #FFFFFF |
| 文字 | #164E63 |
| 補足の文字 | #475569 |
| 枠線 | #A5F3FC |
