# ヨヤクル：企画・要件

更新日：2026年11月4日

## 目的

施術・接客中や営業時間外に電話を受けられない店舗の予約受付を支援する。電話とチャットを共通の予約基盤につなぎ、取りこぼしと受付負担を減らす。

## 方針と状態

| 項目 | 状態 |
|---|---|
| 名称 yoyakuru | ユーザー決定 |
| テナント型SaaS | 要件 |
| 電話・チャットからの予約 | 要件 |
| Googleカレンダー連携 | 要件。双方向同期の詳細は要設計 |
| OpenAI音声AIでの応対 | ユーザー希望・第一候補 |
| Stripeによる店舗への月額課金 | 要件 |
| 伏見整体院を初号店にする | 目標。契約済みではない |
| 電話回線・音声モデル・販売価格 | 未決定 |

## MVP案

- 店舗管理、営業時間、休業日、施術メニューと所要時間。
- 担当者・ベッドなど必要資源と、その同時利用上限。
- 新規予約の空き確認・仮押さえ・復唱・確定。
- 電話とチャットで共通の予約APIを利用。
- カレンダー登録、外部予定の取り込み、同期失敗の再処理。
- 受付履歴、折り返し依頼、利用量、通知。
- 月額課金と支払状態の管理。

変更・取消は初期には折り返し対応とする案。対応を広げる際には予約者確認の手順を設計する。診断や施術可否の判断は院の担当者が行う。

## 導入前の確認

所在地・公式サイト・営業時間・施術内容は未確認。同名施設の情報を流用しない。現状の予約サイト・紙台帳・電話会社・Googleアカウント、当日受付締切、顧客への通知手段を確認する。
