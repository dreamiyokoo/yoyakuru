# 原価・販売価格の検討記録

> 最新の要件は [要件定義 v0.1](requirements.md) を参照してください。本資料は初期検討の記録です。チャット別料金・旧月額など過去の価格は現行方針ではありません。基本機能コミコミ月額1,980円が目標で、番号包含・通話単価などは未確定です。

整理日：2026年11月4日。価格の確約ではない。為替は1ドル150円の仮定。開発費・人件費・税・為替手数料等は別に検討する。

## 従来案：Twilio ConversationRelay＋テキストAI

当日確認したTwilio公開料金で、月100件・平均3分を計算したもの。

| 項目 | 単価・条件 | 月300分の概算 |
|---|---|---:|
| National番号 | 4.75 USD/月 | 712.5円 |
| 通常着信 | 0.01 USD/分 | 450円 |
| ConversationRelay | 0.07 USD/分 | 3,150円 |
| 小計 | 上記のみ | 4,312.5円 |

ここにテキストAI、接続方式による料金、サーバー、決済、保守対応が加わる。Amanesysの試算例5,420円（税込）に価格を合わせても、十分な利益が残るとは判断できない。原価は競合と同じ税込税別の基準にそろえて比較する。

## 現在の第一候補：OpenAI音声APIへ接続

ConversationRelayを使わずOpenAI音声APIへ接続する場合、上記のRelay代をそのまま加算しない。代わりにOpenAIの音声入出力・テキスト／履歴処理等の料金が発生する。

総原価＝番号固定費＋電話・SIP等接続費＋OpenAI API使用額＋共通インフラ配賦＋通知・保存＋決済手数料＋保守対応。

音声の発話割合、モデル、キャッシュ、会話履歴、ツール実行により費用が変わる。通話時間だけからAPI代を断定しない。300分の月間原価は未実測で、同価格で提供できるとの結論はまだない。

## 過去の仮案と目標

- 企画書の実証9,800円、継続14,800円、超過40円/分は初期の提案案（税別）。ユーザー承認済み価格ではない。
- 会話で示した「電話関連原価を300分で2,000円以下」は検証目標。達成済みの数字ではない。
- 共通インフラ月5,000〜15,000円は小規模開始の予算枠。ベンダー見積ではなく、同時接続数や可用性により再検討する。
- Stripeは当日の公開料金として標準カード3.6％＋Billing 0.7％を参照。対象手数料の税、追加機能等を含め正式計算する。

## 計測項目

1. 成立・不成立・無言・長電話を含む全着信の原価。
2. 通話ごとの音声入出力、テキスト、キャッシュ利用量、再試行。
3. 平均・長時間通話、同時通話時の応答遅延。
4. 店舗あたり利用量、通知・録音保持、障害対応工数。
5. 税・決済・インフラ配賦後の店舗別粗利。
