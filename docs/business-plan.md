# ヨヤクル 事業方針

整理日：2026年11月5日  
経営評価（2026-11-05）を受けて定めた方針。機能の仕様は[要件定義](requirements.md)、競合の状況は[競合分析・機能比較](competitor-analysis.md)を参照。

## 1. 方針

| ID | 方針 |
|---|---|
| BIZ-01 | 打ち出しを「施術中でも電話を取りこぼさない、AI受付つき予約台帳」に絞る。無料の予約システムと同じ土俵（Web予約だけ）で戦わない |
| BIZ-02 | 最初の販売対象は、整体・治療院（個人〜3名、電話予約が中心、施術中は電話に出られない店）とする。作りは汎用（GEN-01〜04）のまま、売り方だけ業種を絞る |
| BIZ-03 | AI電話の原価・品質の検証（[Issue #1](https://github.com/dreamiyokoo/yoyakuru/issues/1)）を最優先とする。成立すれば、AI電話を実証導入の範囲に含める（8章） |
| BIZ-04 | 価格は「電話プラン3,980円（税込）」を主力、1,980円（税込）を入口のプランとする案で検討する。年払いの割引と、初期設定の代行（有料、またはAIチャットによる設定で無料）も検討する。金額と枠はIssue #1の結果で確定する |
| BIZ-05 | ヒアリングは伏見整体院だけでなく、整体・治療院5〜10店で行う。特に、電話の取りこぼし件数と、払ってもよい金額を聞く |
| BIZ-06 | 撤退・方針転換の基準を事前に定める。①AI電話の原価が、miniモデルでも1分12円を超える場合は、電話の構成を見直すかAI電話をやめる。②実証導入した店舗が3,980円を払わない場合は、価格か対象業種を見直す |
| BIZ-07 | 売上への寄与が小さい機能は後回しにする。MCP（MCP-01〜10）と定員制の枠の画面（EXT-07〜08）は実証導入の後とする。AIチャットによる設定（SETUP）は、導入支援の手間と顧客獲得費を下げるため優先する |
| BIZ-08 | AI電話の検証（Issue #1）が成立しない場合の次の手を、次の順に検討する。①音声認識・テキストAI・音声合成を組み合わせた構成に切り替えて再検証する。②AIが電話で予約を確定せず、用件の聞き取りと折り返し受付に機能を絞る（通話を短くして原価を下げる）。③電話をやめ、AIチャットによる設定とAIチャット予約で売る。③は差別化が弱いため、価格と対象業種を見直す |
| BIZ-09 | 販売経路を、ヒアリング（1〜2週）と並行して決める。候補は、整体・治療院の業界団体、治療院向けのコンサルタント・代理店、経営者のコミュニティ、既存店舗からの紹介制度。経路ごとに、1店舗あたりの獲得費用の見込みと、価格の上限を比較する。5〜10店のヒアリング先も、同じ経路の候補から集めて、経路の有効性を確かめる |
| BIZ-10 | 導入支援とサポートの範囲を、実証導入の前に決める。AIチャットによる設定（SETUP）で設定作業は軽くなるが、電話の転送設定は人の支援が必要になる見込み。初期費用を取るか無料にするか、サポートの手段（チャット・電話・訪問）と対応時間を決め、収益性の試算に入れる |

## 2. 90日の進め方（案）

| 時期 | やること | 判断 |
|---|---|---|
| 1〜2週 | AI電話の原価・品質の検証（Issue #1）、整体・治療院5〜10店のヒアリング（BIZ-05） | AI電話を続けるか（BIZ-06の①） |
| 3〜8週 | 予約台帳とAI電話の最小版の開発。MCP・定員制の枠の画面は後回し | — |
| 9〜12週 | 2〜3店で実証導入。電話の応答率、予約の完了率、受付時間の削減、払ってもよい金額を測る | 価格と対象業種の確定（BIZ-06の②） |

## 3. 判断の材料

| 判断 | 材料 | 時期 |
|---|---|---|
| AI電話を続けるか（BIZ-06の①、BIZ-08） | AI電話の原価・品質の実測（[Issue #1](https://github.com/dreamiyokoo/yoyakuru/issues/1)） | 1〜2週 |
| 販売経路（BIZ-09） | ヒアリング先の集まり方、経路ごとの獲得費用の見込み | 1〜2週 |
| 価格と対象業種（BIZ-04、BIZ-06の②） | ヒアリングでの電話の取りこぼし件数と払ってもよい金額、実証導入の結果 | 9〜12週 |
| 導入支援とサポート（BIZ-10） | 実証導入での支援の手間 | 実証導入の前 |
