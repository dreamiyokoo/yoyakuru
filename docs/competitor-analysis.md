## 3. 分析

### 価格の位置づけ

- 予約システム型は、無料プラン（月50件程度）があり、月4,000円前後で月200件まで使える価格帯が中心。
- AI電話型は、月4,000円前後から。基本料とは別に、電話番号の維持費や通話の従量がかかる。
- ヨヤクルの1,980円（税込）は、どちらの型と比べても低価格帯に入る。

### ヨヤクルの差別化ポイント

1. **Web・チャット・電話を1つの予約台帳で扱う**：予約システム型は電話をAIで受けず、AI電話型は担当者や設備の制約を扱う予約台帳を持たない（いずれも公開情報の範囲）。両方を1つにまとめている点が最大の違い。
2. **AIチャットで初期設定が終わる**（SETUP）：機能が多い予約システムほど初期設定が負担になる。会話だけで設定が終わる点は、導入の障壁を下げる。
3. **汎用の作り**（GEN、EXT）：指名・設備・定員制を、業種ごとのコードではなく設定で扱う。
4. **MCP対応**：AIアシスタントから休み・シフトを管理できる。公開情報の範囲では、他社に例を確認できなかった。
5. **会員登録なしで予約でき、GoogleとLINEのログインも選べる**。

### ヨヤクルの弱み

- **無料プランがない**：STORES予約・RESERVAは無料で月50件まで使える。1,980円を払う理由（AIの価値）を示せないと、無料プランに負ける。
- **事前決済がない**：無断キャンセル対策や前払いを重視する店舗には不利。
- **Googleカレンダー連携とLINE通知が後続**：Airリザーブ等と比べて、連携の面で見劣りする。
- **実績がない**：初号店の導入事例が最初の材料になる。

## 4. 提案

1. **利用枠の数え方を見直す**：今の案（USAGE-01）は、電話とチャットの確定予約を数える。選択式のWeb予約はAIを使わず原価がほぼかからないため、件数の上限の対象外（無制限）にすると、無料プランの月50件や、Airリザーブの「予約件数無制限」と比べて見劣りしない。上限は、AI（チャットの自由入力・電話）が関わった予約に絞る。要件書のUSAGE-01・01aに反映済み（2026-11-05）。
2. **無料の試用期間を設ける**：無料プランの代わりに、一定期間の無料試用で、AIチャットでの初期設定とAIチャット予約の価値を体験してもらう。
3. **AI電話の価格は、競合に合わせる**：Amanesys（Minimum：従量、Starter：3,980円・120件・180分）、IVRy（スターター3,980円〜）の価格帯に合わせる前提で、原価を検証する（[Issue #1](https://github.com/dreamiyokoo/yoyakuru/issues/1)）。
4. **事前決済は後続で検討する**：無断キャンセルの状況（ヒアリング、REMIND-05）を見て優先度を決める。
