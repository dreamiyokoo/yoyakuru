# 伏見整体院 ヒアリングシート

作成日：2026年11月4日  
目的：ヨヤクルの初号店導入に向けて、現在の業務と予約の状況を確認し、要件（[要件定義 v0.2](requirements.md)）の前提を見直す。  
所要時間の目安：30〜45分。事前に送付し、当日は空欄を一緒に埋める。

## 当日の注意

- 料金は未確定（原価検証中、[Issue #1](https://github.com/dreamiyokoo/yoyakuru/issues/1)）。金額は約束しない。
- AI電話はMVPの対象外（後続フェーズ）。電話の質問は将来の準備として聞く。
- 症状や病歴などの健康情報は、ヨヤクルでは受け取らない方針（PRIV-01）。問診票の運用は「来店時のまま」でよいか確認する。
- メニュー表・料金表があれば、写真またはPDFでもらう。
